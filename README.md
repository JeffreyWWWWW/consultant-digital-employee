本仓库用于沉淀和管理“咨询顾问”岗位数字员工建设需求，包括原始需求说明书、需求摘要、后续评审记录、实施拆解和验收口径。

## 目录

- `docs/source/`：原始 Word 文档及附件
- `docs/requirements/`：便于版本管理的 Markdown 需求稿

## 当前内容

- 岗位：咨询顾问
- 部门：咨询与方案部
- 建设目标：围绕方案初稿生成、投标辅助、政策案例检索、资料检索、PPT 生成等场景，提升效率、控制质量、降低新人上手门槛，并保证来源可追溯和数据安全。
