10. 优化 `generate_docx.py`，支持来源清理、无链接案例降级、政策无来源降级、生成用时输出。
11. 将 ZX-01 主流程调整为“需求解析 → Tavily 联网检索 → 产品/案例匹配 → 生成初稿 JSON → 自动质检审稿 → 修正 JSON → Word 输出”。
12. 增加“建设情况汇报/成效汇报”文档类型路由，支持“总体概况 → 场景建设成效 → 下一步计划”的汇报型结构。
13. 输出 ZX-01 Skill 流程图与架构图，便于对外说明整体能力链路。

## 主要优化

- 避免政策机械套用，改为按项目主题匹配政策依据。
- 正文不再内嵌长链接，来源统一放到附录C，便于人工复核。
- 去掉无依据的“来源占比”，改为“内容来源说明”。
- 明确方案为 AI 辅助初稿，政策、产品、预算、案例均需人工审核确认。
- 强化 Word 输出格式，使方案更接近正式交付文档。
- 区分解决方案与建设情况汇报，避免所有需求都硬套七章方案结构。
- 统一对外身份名称为“「咨询顾问-卓智」数字员工”。
