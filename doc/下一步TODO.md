# 咨询顾问数字员工下一步 TODO

## 总体目标

将 智能方案初稿生成 从“能生成方案初稿”推进到“写得准、写得像专家、来源可追溯、结果可验收”。

建议优先建设顺序：

```text
产品能力清单
→ 案例库结构
→ 自动质检器
→ ZX-03 政策与案例检索模块
→ 验收测试集
→ 演示文稿智能生成
→ ZX-02 投标文件辅助生成
```

## P0：产品能力清单

### 目标

解决方案中产品匹配不能只靠模型判断，必须优先来自公司产品库，避免虚构产品能力。

### TODO

- [ ] 梳理卓繁现有产品和能力模块。
- [ ] 建立产品能力清单字段：
  - 产品名称
  - 适用客户类型
  - 适用场景
  - 核心能力
  - 可写入方案的话术
  - 禁止承诺内容
  - 关键词
  - 关联案例
- [ ] 形成结构化数据文件，如 `product-capabilities.json` 或知识库表。
- [ ] 在 智能方案初稿生成中优先按关键词匹配产品能力。
- [ ] 无法确认产品能力时，统一标注 `待确认`。

### 验收标准

- [ ] 方案中产品名称均能追溯到产品能力清单。
- [ ] 未命中的产品不会被模型编造。
- [ ] 产品匹配准确率可人工抽检。

## P0：案例库结构

### 目标

把优秀历史案例沉淀为可复用资产，减少每次都依赖联网检索。

### TODO

- [ ] 设计案例库字段：
  - 项目名称
  - 客户单位
  - 客户类型
  - 区域
  - 行业/主题
  - 建设内容
  - 方案亮点
  - 量化成效
  - 来源链接
  - 是否可对外引用
  - 脱敏状态
- [ ] 先录入 10 个高质量案例。
- [ ] 标注案例适用场景，如政务大厅、一网统管、数据共享、基层治理等。
- [ ] 在 智能方案初稿生成中优先查案例库，未命中时再走 Tavily 联网检索。

### 验收标准

- [ ] 每个案例都有来源或脱敏说明。
- [ ] 方案引用案例时能写入附录C。
- [ ] 不可对外引用案例不会进入正式方案正文。

## P0：自动质检器

### 目标

让方案生成后自动检查结构、来源、产品、案例、政策和语言质量，而不是只靠人工看。

### TODO

- [ ] 基于 `quality-checklist.md` 设计质检输出 JSON。
- [ ] 检查七章结构或汇报型结构是否完整。
- [ ] 检查痛点、目标、建设内容是否一一对应。
- [ ] 检查政策、行业资料、案例是否进入附录C。
- [ ] 检查正文是否存在 URL、`[来源：...]`、AI 套话。
- [ ] 检查产品能力是否来自产品库或标注 `待确认`。
- [ ] 检查量化指标是否有依据或标注待确认。
- [ ] 自动生成 `review_notes` 并写回方案 JSON。

### 验收标准

- [ ] 每次 Word 输出前必须先跑质检。
- [ ] 质检结果能指出问题位置和修改建议。
- [ ] 常见问题可自动修正或降级标注。

## P1：ZX-03 政策与案例智能检索模块

### 目标

把政策、案例、行业资料检索独立出来，作为 智能方案初稿生成的前置能力。

### TODO

- [ ] 定义统一检索输入：
  - 区域
  - 客户类型
  - 核心需求
  - 关键词
  - 文档类型
- [ ] 定义统一检索输出：

```json
{
  "policies": [],
  "cases": [],
  "industry_sources": [],
  "search_status": "",
  "risk_notes": []
}
```

- [ ] 使用 Tavily 按短 query 检索政策。
- [ ] 每个成功案例单独检索。
- [ ] 对来源进行分级：
  - 已核验
  - 待核验原文
  - 待联网核验
- [ ] 将检索结果直接写入 智能方案初稿生成的 `policy_sources`、`industry_sources`、`cases`。

### 验收标准

- [ ] 不联网不写已核验来源。
- [ ] 每条政策、案例都有 URL 或明确待核验状态。
- [ ] 检索失败会写明失败降级原因。

基于已生成的方案或建设情况汇报，自动生成一版可汇报的演示文稿初稿，减少顾问从 Word 到演示文稿的内容提炼和排版时间。

- [ ] 梳理公司演示文稿模板：
  - 深蓝模板
  - 浅蓝模板
  - 封面页
  - 目录页
  - 章节页
  - 内容页
  - 图表页
  - 结束页
- [ ] 设计演示文稿内容结构：
  - 项目背景
  - 建设目标
  - 核心痛点
  - 建设内容/场景成效
  - 技术架构
  - 实施计划
  - 预期效益
  - 下一步计划
- [ ] 支持区分两类演示文稿：
  - 解决方案汇报演示文稿
  - 建设情况/成效汇报演示文稿
