# 项目汇报结构


适用范围：

- 项目需求阶段的项目汇报、项目建议支撑材料或方案初稿。
- 面向领导、客户或内部评审，说明“为什么建、准备建什么、依据是什么”。
- 会议纪要、沟通记录、任务安排、需求文档等只是常见输入材料。
- 只有材料内容指向项目建设沟通、立项/评审支撑或需求阶段方案初稿时，才使用本结构。

### 标题

```
{客户单位}{项目名称}建设项目汇报
```

标题规则：

- 标题直接写材料标题，不加书名号《》。
- 标题字体必须为 `方正小标宋_GBK`，字号为二号（22pt）。
- 不得追加“解决方案”“解决方案（初稿）”“（初稿）”等字样。
- 如果项目名称已包含“建设项目汇报”或“汇报”，保持用户/材料中的正式标题。
- 如果项目名称已以“建设”结尾，标题拼接为 `{客户单位}{项目名称}项目汇报`，不得写成“建设建设项目汇报”。

正文字体规则：

- 正文字体必须为 `仿宋_GB2312`，字号为三号（16pt）。

文件命名规则：

```
{客户单位}{项目名称}建设项目汇报_{YYYYMMDD}.docx
```

项目汇报文件名不得使用内部过程命名或解决方案初稿命名。

### 一、项目建设的依据

写作要求：

- 优先检索并引用与项目直接相关的国家级、省市级、区县级和主题专项政策。
- 资料来源必须按 `references/search/policy-web-search.md` 执行检索和核验，并在结构化 JSON 中写入 `sections.policy_sources` 或等价来源字段。
- 政策必须围绕项目建设必要性展开，不做泛泛政策背景铺陈。
- 对于区县项目，应优先体现本地区政府职能转变、营商环境、一网通办、人工智能+政务服务、政策精准推送等直接依据。
- 每条政策说明其对项目的支撑关系，例如“为政策匹配、智能推荐、服务包升级提供依据”。
- 政策名称、发文单位、文号、发布时间和原文链接必须进入附录A；无法核验原文链接时标注 `待核验原文` 或 `待联网核验`。
- 结尾说明这些文件共同支撑项目合法性、合理性和实施方向。

### 二、建设目标

写作要求：

- 先用一段话说明本项目是在什么既有系统或服务基础上升级。
- 再说明本次建设要达成的目标：页面优化、功能完善、移动端适配、政策匹配、数据互联互通等。
- 对会议纪要中明确出现的目标和范围，应优先原样转为正式表达。
- 不写宏大的“全国领先、标杆示范”等口号，除非用户材料明确要求，且标注待确认。

### 三、建设内容

写作要求：

- 优先抽取会议纪要、需求清单、历史方案中的具体建设项，不要泛化成标准系统模块。
- 按实际建设事项组织，每项采用“事项名称 + 建设动作 + 业务价值”的写法。
- 建设内容下的具体事项使用二级序号，格式为 `（一）事项名称`、`（二）事项名称`、`（三）事项名称`。
- 不显式写“产品匹配”标签，除非用户明确要求内部售前方案。
- 不默认写技术架构、成功案例、预算、实施计划和项目组织。
- 需要保留附录，附录只用于承载来源链接、待核验内容和人工审核提示；不得默认扩展为技术架构、案例、预算或实施组织材料。

推荐建设内容颗粒度：

- 页面优化；
- 功能完善；
- 终端或移动端适配；
- 政策匹配；
- 数据互联互通；
- 与第三方平台或本地服务渠道对接。

### 附录A：政策与资料来源链接

写作要求：

- Word 文档末尾必须保留本附录，用于人工审核，不作为正文主体章节。
- 本附录必须另起一页。
- 附录A的来源必须来自 `policy-web-search.md` 要求的检索/核验记录，不得使用模型记忆补写来源。
- 应列出政策名称、发文单位或来源机构、文号/发布时间（如有）、原文链接或核验状态，以及在正文中支撑的内容。
- 已找到原文链接的来源必须附上链接；链接应以可复制、可点击或完整 URL 形式写入文档。
- 无法核验原文链接时标注 `待核验原文` 或 `待联网核验`。
- 附录不得写成长篇正文，不得替代顾问人工复核。

### 附录B：需人工审核事项

写作要求：

- Word 文档末尾必须保留本附录，用于列出需人工确认和复核的事项。
- 本附录必须另起一页。
- 应列出未核验政策、待确认产品能力、待确认建设范围、待补充材料、量化指标待测算等内容。
- 附录B开头必须说明：文中黄色标注内容为需人工核对事项。
- 正文和附录B中凡标注 `待核验`、`待确认`、`待补充`、`待测算`、`需人工审核`、`需人工复核`、`推断`、`建议`、`未核验`、`模型生成`、`模型建议` 的内容，应在 Word 中用黄色高亮提示人工核查。
- 对于由模型根据材料推断、补写或无法从来源直接证明的内容，应写入 `sections.review_highlights` 或 `sections.manual_review_terms`，生成 Word 时对对应正文片段标黄。
- 附录不得写成长篇正文，不得替代顾问人工复核。
