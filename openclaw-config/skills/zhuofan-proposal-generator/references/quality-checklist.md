# 质量检查索引

本文件用于快速定位不同交付物的质量检查清单。执行时先判断 `document_type`，再读取对应 checklist。

- 质量检查路由：`quality-routing.md`
- 项目汇报 / 项目建议支撑材料：`quality/project-report-checklist.md`
- 项目需求阶段解决方案初稿：`quality/solution-draft-checklist.md`
- 建设情况汇报 / 成效汇报：`quality/achievement-report-checklist.md`

先读取 `quality-routing.md` 判断 checklist，再只读取对应质量检查文件。不要一次性加载全部 checklist。
