# 文档结构索引

本文件用于快速定位不同交付物的结构规则。执行时先判断 `document_type`，再读取对应结构文件。

- 文档类型路由：`proposal-routing.md`
- 项目汇报 / 项目建议支撑材料：`structures/project-report.md`
- 项目需求阶段解决方案初稿：`structures/solution-draft.md`
- 建设情况汇报 / 成效汇报：`structures/achievement-report.md`

先读取 `proposal-routing.md` 判断 `document_type`，再只读取对应的结构文件。不要一次性加载全部结构。
