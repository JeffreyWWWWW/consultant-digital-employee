# 来源核验规则

本文件用于判断外部资料是否可以作为已核验来源写入材料。搜索工具只负责“找到线索”，本文件负责判断“能不能用、怎么标注”。

## 核验结论

来源核验结论只使用以下状态：

- `已核验原文`：模型已打开并确认原文页面，页面属于原始发布方、主管机构、项目主体或正式公开平台，且标题、发布机构、发布时间等要素与材料表述一致。
- `待核验原文`：找到可能来源或转载链接，但未确认原始来源。
- `待联网核验`：需要检索但当前未能完成检索或打开核验。
- `未找到原文`：已检索多个方向仍未找到原文。

只有 `已核验原文` 可作为已核验依据。其他状态必须进入人工审核事项。

人工审核是交付后的复核动作，不写入 `verification_status`。如果用户或顾问后续人工确认来源，应在人工审阅结论中说明，不由模型生成新的核验状态。

## 原文判定

满足以下条件，才可标记为已核验原文：

- 页面域名属于原始发布方、主管机构、项目主体、地方政府或其正式公开平台。
- 页面标题与政策、规划、方案、通知、报告、案例、产品资料或公开信息名称一致或高度一致。
- 发布机构、发布时间、文号、项目主体、产品名称等关键要素与材料表述一致；没有文号的资料，应核对标题、发布机构和发布时间。
- 页面正文或附件能够支持材料中的引用内容。
- 页面不是无原始信息的新闻报道、媒体转载、公众号文章、商业平台聚合页、解读页或单纯下载中转页。

## 来源类型

检索结果应标注 `source_type`：

- `官网原文`：原始发布方、主管机构或项目主体官网原文。
- `政府公开平台`：政府政策库、公开栏目、政务服务平台等正式公开页面。
- `机构原文`：行业协会、标准组织、研究机构、厂商或其他机构的原始发布页面。
- `主体公开页面`：项目主体、客户或相关单位的公开页面。
- `政府转载`：政府相关网站转载，非发文机关原文。
- `媒体转载`：新闻媒体、商业网站、公众号、行业网站转载。
- `线索页`：只提供标题、摘要、附件线索或二次引用，不能直接作为原文。
- `未确认`：无法判断来源性质。

`政府转载`、`媒体转载`、`线索页`、`未确认` 均不得标记为已核验原文。

## 来源优先级

来源按以下顺序优先：

1. 原始发布方、主管机构、项目主体或客户官网。
2. 国务院、部委、中央机关官网，例如 `gov.cn`、部委官网。
3. 省、市、区县人民政府官网和政府办公厅官网。
4. 行业协会、标准组织、研究机构、厂商官网或正式公开平台。
5. 政府相关网站转载或权威媒体报道。
6. 商业媒体、公众号、聚合页。

优先级 1-4 仍需打开页面核验原文要素；优先级 5-6 只能作为反查原文的线索。

## 转载反查原文

如果先搜到的是转载页，应继续反查原文：

- 使用完整资料标题加发布机构搜索。
- 使用资料标题加文号、项目主体、产品名称或发布时间搜索。
- 使用 `site:` 限定原始发布方、主管机构、项目主体或政府官网域名搜索。
- 如果转载页提到附件名称，应使用附件名称反查官网页面。

反查后仍找不到原文的，附录A可保留转载链接作为线索，但核验状态必须为 `待核验原文`，并在附录B写明需要核验的原始来源。

## 写入结构

建议 `sections.sources` 每条来源使用以下字段：

```json
{
  "name": "来源名称",
  "agency": "发布单位或来源机构",
  "doc_no": "文号（如有）",
  "date": "发布时间（如有）",
  "url": "原文链接或线索链接",
  "source_type": "官网原文/政府公开平台/机构原文/主体公开页面/政府转载/媒体转载/线索页/未确认",
  "verification_status": "已核验原文/待核验原文/待联网核验/未找到原文",
  "used_for": "支撑的正文内容",
  "query": "实际检索词",
  "search_provider": "Tavily/百度/Tavily+百度/用户提供"
}
```

## 附录联动

- `verification_status` 为 `已核验原文` 时，可只进入附录A。
- `verification_status` 不是 `已核验原文` 时，必须同时进入附录A和附录B。
- 附录B中应说明具体需要核验什么，例如原始来源、发布单位、文号、发布时间、附件内容或引用内容。
- 如果附录A已有线索链接，附录B对应批注应带上线索链接，便于人工复核。
